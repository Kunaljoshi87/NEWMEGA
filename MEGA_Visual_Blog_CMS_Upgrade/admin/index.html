Publish a blog without coding

Authorized editors sign in to Pages CMS with GitHub, create an article, upload a feature image and save.

Open secure Blog Editor →

How it works

  1. Sign in to Pages CMS using an approved GitHub account.
  2. Select repository Kunaljoshi87 / NEWMEGA.
  3. Choose Blog articles, then New entry.
  4. Enter the article title, publication date, category, SEO description and image.
  5. Write using the rich-text editor and turn on Publish on website.
  6. Save. GitHub Actions rebuilds the public blog automatically.

Security: Access depends on repository permissions. No passwords are embedded in this site.
